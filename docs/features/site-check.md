# F11 · Site check (planned)

Last updated: 2026-10-12 · Status: planned · Open decision

## Idea
- When a visitor gives their website, Cuso reads it and comes back with three real findings (SEO, messaging, social).
- Strongest possible hook for signups: the visitor gets value before the product launches.

## What it needs
- A small backend: fetch the site, extract text and meta, ask a model for three findings in Cuso's voice.
- Abuse limits (rate limit per IP, URL allow rules) and a timeout.
- Shown in the 07:00 Brand Brain card, replacing the sample rows.
